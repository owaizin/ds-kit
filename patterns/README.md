# Application patterns

Original recipes assembled from the kit's foundations. Read [layout and composition](../foundations/layout-composition/README.md) first, then the recipe for the task:

- [Collections](collections.md): records, filters, summaries and empty results.
- [Settings](settings.md): explanatory sections, fields, errors and save feedback.
- [Detail](detail.md): record identity, facts, primary content and activity.

These specify relationships and acceptance checks, not a framework API or copied template. [Original examples](../specimens/application-ui/index.html) exercise them with the existing options. [Benchmark register](../docs/application-ui-benchmarks.md) separates observations from kit recommendations.

For metadata or catalog work, follow the [registry guidelines](../docs/registry-guidelines.md). Catalog these as recipes; component entries require an actual public implementation in the consuming library.
